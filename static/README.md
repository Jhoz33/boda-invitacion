# Lilac Garden - Mockup Fixdate

Maqueta inversa de https://www.fixdate.io/pe/modelo-invitacion/lilac-garden

## Uso
Abre `index_local.html` en tu navegador. Todos los assets están locales.

Estructura:
- `index_local.html` → versión con rutas relativas
- `modelo-invitacion/133/` → CSS, JS, img del modelo
- `recursos-variantes-modelos/133/6/` → fuentes, vars, favicons
- `producto/` `services/` `public/` → dependencias

Para personalizar:
1. Cambia textos en `index_local.html`
2. Edita colores en `recursos-variantes-modelos/133/6/css/vars.css`
3. Reemplaza galería en `modelo-invitacion/133/img/galeria/`

Los formularios de asistencia siguen apuntando a servicios de Fixdate.
